Goodman Furnace Code E4: Open High-Limit Switch

Goodman furnace code E4 means furnace overheated and the high-limit safety switch shut it down to prevent damage or fire. Most often from clogged air filter restricting airflow. You can check basics first; professional repairs typically run $150–$600.

What it means

Goodman furnace code E4 means furnace overheated and the high-limit safety switch shut it down to prevent damage or fire. Most often from clogged air filter restricting airflow. You can check basics first; professional repairs typically run $150–$600.

Try this first

  1. 1Turn off the furnace at the switch.
  2. 2Check the air filter; replace if dirty.
  3. 3Open all supply vents.
  4. 4Restore power and see if the code clears.

What a repair costs

A limit switch replacement typically costs between $150 and $600 nationally.
